# SWAN project continuity

- Read RESUME.md for the current implementation checkpoint.
- Maintain DEFERRED-WORK.md whenever requested work, verification or accepted scope
  is skipped, blocked, deferred or held for later. Record the reason and closure
  requirement; preserve stable IDs and link evidence when resolving an item.
- Keep planned implementation distinct from actual-market acceptance and from
  explicitly excluded scope. Do not mark a milestone complete from fixtures alone.
- Preserve the user's request to skip broker login/live-market checks until they
  explicitly resume that acceptance work. Do not relax trading permission gates.
